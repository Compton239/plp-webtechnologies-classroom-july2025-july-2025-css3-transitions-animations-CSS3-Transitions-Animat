# 🎬 CSS & JavaScript Animation Assignment

## 📌 Overview
This project demonstrates how to combine **CSS3 animations** with **JavaScript functions** to build an interactive and visually dynamic web page.

---

## 🎨 Features
### Part 1: CSS3 Animations
- Button hover transition (scaling + color change)
- Animated box with `@keyframes` pulse effect

### Part 2: JavaScript Functions
- Custom functions with parameters & return values
- Demonstrates **local vs global scope**
- Example: multiplyNumbers(a, b) returns result × globalMultiplier

### Part 3: CSS + JS Integration
- Button triggers bounce animation on a box
- Popup modal with slide-in animation (open/close via JS)

---

## 📂 Files
- `index.html` → Main structure  
- `styles.css` → CSS transitions, animations, modal styling  
- `script.js` → Functions + animation triggers  
- `README.md` → Documentation  

---

## 🛠️ How to Run
1. Open `index.html` in a browser.  
2. Try hovering over the button, clicking the counter, animating the box, and opening the modal.  
3. Open console to see function calculations.

---

## 🎯 Learning Outcomes
- Built **CSS animations** with `@keyframes` and transitions  
- Wrote **JavaScript functions** with scope, parameters, and return values  
- Integrated **JS + CSS** for dynamic interactivity  
- Improved user experience with animations and modals
